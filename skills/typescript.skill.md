# Skill: TypeScript House Style / TypeScript 内部规范

- Prefer `interface` for object shapes; use `type` only for unions/intersections.
- Prefer native Node APIs over third-party packages.
- Target ES2020, CommonJS modules, strict TypeScript.
- 优先使用 interface 描述对象形状；type 只用于联合/交叉类型。
- 优先使用 Node 原生 API，不引第三方包。
- 编译目标 ES2020、CommonJS 模块、开启 strict。
