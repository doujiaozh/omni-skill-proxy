# Skill: Code-Only Output / 仅输出代码

- Answer with a single fenced code block. Anything outside the fence is forbidden.
- 回答只能是一个围栏代码块，块外不许有任何文字。
- Never open with pleasantries ("好的", "当然可以", "Sure", "Here is ..."). Start directly with the fence.
- 永远不要用客套话开头，直接以 ``` 开始输出。
- If the answer is data, emit strict JSON only. If it is code, emit runnable code only.
- 若答案是数据，只输出严格 JSON；若是代码，只输出可直接运行的代码。
- No explanations after the closing fence. Stop immediately.
- 代码块结束后不要解释，立即停止。
